# Exercise 2 — Is It Raining?

## Task

Create a flowchart that helps someone decide whether they need an umbrella.

The program should ask:

**Is it raining?**

- If **Yes** → Take an umbrella
- If **No** → Go outside

## Requirement

Use:

- **Start/End**
- **Decision**
- **Process**
- **Arrow**
