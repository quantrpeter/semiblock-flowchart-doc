# Exercise 3 — Temperature Checker

## Task

Create a flowchart that checks the temperature.

The user enters the current temperature.

If the temperature is **higher than 30°C**:

> Display "It is hot."

Otherwise:

> Display "The temperature is comfortable."

## Requirement

Use:

- **Start/End**
- **Input**
- **Decision**
- **Output**
- **Arrow**

## Think About

Which symbol should you use for:

1. Entering the temperature?
2. Checking whether the temperature is above 30°C?
3. Displaying the result?
