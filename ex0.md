# Flowchart Exercises

Welcome to the **Flowchart Exercise Section**.

These exercises will help you practise using different flowchart symbols and understand how flowcharts can be used to solve problems.

The exercises become gradually more challenging.

---

## Exercise 1 — Making a Cup of Tea

Learn how to create a simple flowchart using a sequence of steps.

[Start Exercise 1](ex1.md)


## Exercise 2 — Is It Raining?

Learn how to use a **Decision** symbol to create different paths.

[Start Exercise 2](ex2.md)


## Exercise 3 — Temperature Checker

Practise using **Input**, **Decision**, and **Output** symbols.

[Start Exercise 3](ex3.md)


## Exercise 4 — Pass or Fail

Create a flowchart that makes a decision based on a student's score.

[Start Exercise 4](ex4.md)


## Exercise 5 — Smart Light System

Create a flowchart for an automatic system using sensors, decisions, and a loop.

[Start Exercise 5](ex5.md)


## What You Will Practise

By completing these exercises, you will learn how to use:

- Start / End
- Process
- Input
- Output
- Decision
- Arrow
- Sequence
- Conditions
- Loops
