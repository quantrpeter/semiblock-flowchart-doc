# Exercise 4 — Pass or Fail

## Task

Create a flowchart that checks a student's test score.

The user enters a score from **0 to 100**.

If the score is **50 or above**:

> Display "Pass"

If the score is **below 50**:

> Display "Fail"

## Requirement

Your flowchart should contain:

1. Start
2. Input the score
3. Check whether the score is 50 or above
4. Display the result
5. End

Use:

- **Start/End**
- **Input**
- **Decision**
- **Output**
- **Arrow**

## Challenge

Add another condition:

- 80 or above → **Excellent**
- 50–79 → **Pass**
- Below 50 → **Fail**
